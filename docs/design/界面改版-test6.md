# 拉比克 Test6 界面改版

2026-10-19。根据用户确认的 Stitch 精简概览方案和“Logo 使用简单线条”的要求实施。

## 已实现

- 概览只保留常用操作、系统权限和开机启动；移除大品牌卡片、重复状态、长说明与侧栏清空入口。
- 设置窗口使用 clear 背景、非 opaque 窗口和 behind-window 的系统材质；保留系统减少透明度等辅助功能设置的优先级。支持调整窗口大小。
- 设置按概览、通用、剪贴板、截图与钉图、快捷键、识别与翻译、关于归类，原有选项继续保留。
- 简洁兜帽轮廓与两条眼睛线构成品牌图标，共用一份矢量绘制代码生成应用图标、菜单栏模板图与界面标记。
- 历史面板默认 920×620，可调整大小；单击预览，双击确认（遵循自动粘贴选项），⌥单击仅复制，⌘单击多选。悬停只显示辅助按钮，不改变选中项。
- 搜索、筛选字号和命中范围增大；标签可以横向滚动；来源显示应用名，详情不显示内容哈希。复制与粘贴固定在底部，清空收进更多菜单并保留确认。
- 截图采用单行图标工具栏，40pt 命中范围，绿色情境选中；颜色、字号和线宽按工具显示。窄屏工具栏可横向滚动，位置继续限定在当前屏幕。
- 编辑已有文字时仍显示颜色和字号参数；提示统一为 Enter 换行、点击空白完成、再次点击文字编辑。既有红色默认、无背景、拖动文本与放大镜行为保留。

## 验证

- 构建成功；原有 XCTest 60 项与截图 Swift Testing 25 项全部通过。
- 原工具栏与新工具栏的多屏窗口像素对照结果一致。原测试要求纯红在窗口缓存中蓝通道低于 0.1，但当前显示器色彩配置下红色样本的蓝通道约 0.178；窗口测试改为主通道大于 0.8、红蓝主次差大于 0.65，仍能在两种屏幕内容对调时失败。图像输出测试保留原有像素检查。
- 使用隔离数据生成浅色/深色概览、剪贴板、各设置分类与截图实际布局预览。界面预览不连接桌面截图，也不修改真实剪贴板内容。
- 打包在本机临时目录进行，避免同步桌面目录在清理后重新添加 FinderInfo 破坏签名。
- 沿用现有 bundle ID、可执行文件名和固定签名证书；签名脚本继续验证与已安装版本的 designated requirement 一致。
