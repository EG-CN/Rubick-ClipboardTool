# T1 功能交接规格（未完成 4 项，下一会话直接照此实现）

> 已完成：延时截图⌘⇧G、覆盖层取色器。以下 4 项规格已定，实现即可。

## 1. 贴图增强包
- 鼠标穿透：PinModel 加 `passThrough: Bool`（菜单项切换）；开启时 `panel.ignoresMouseEvents = true`，穿透态贴图加 1px 虚线边提示；关闭方式：热键（新增 Action 或 ⌥⌘P 全局）遍历 pins 关闭全部穿透
- 旋转：PinModel 加 `@Published var angle: CGFloat`；菜单"旋转 90°"；视图 `.rotationEffect(.degrees(model.angle))`；contentSize 按旋转后包围盒计算
- 管理面板：新 PinManagerPanel（复用 Dock 形态，列出 pins 缩略图+显隐+关闭全部）；入口：贴图右键菜单"管理贴图"

## 2. 截图美化（导出加壳）
- 标注编辑器加第 9 工具 `.beautify`（或确认按钮旁"美化"菜单）：选项=圆角半径(0/12/20)、阴影(无/柔和)、背景(无/白/黑/渐变A/B)
- flatten：先画背景（纯色或渐变矩形，尺寸=选区+2×padding），再圆角裁剪内容，再叠阴影（CGContext shadow）
- 预览同步：drawPreview 同语义（背景→clip→阴影）

## 3. 多窗口拼接截图
- overlay pending 态：⌘+单击窗口 = 加入/移出拼接集合（Set<CGRect>，高亮持续显示）
- ↵：取所有选中窗口的包围盒 → 复用 ImageCompose.composite 逻辑（背景填充深色）→ 逐窗裁剪叠加 → 进编辑器
- Esc/单击空白 = 取消集合

## 4. 涂抹打码（画笔式马赛克）
- 标注新工具 `.smudge`（键位 9）：拖拽收集 points（同画笔）
- 预览：沿 points 每点画马赛克圆（半径=lineWidth*2，从 mosaicTiny 取样对应区域）
- flatten：draw(.smudge) 沿点采样 baseCG 对应位置像素块填充圆
- 与现有框选马赛克并存

## 注意
- 所有新工具记入 AnnotateKeys（toolSmudge=0? 键位用 0）+ 工具栏 + 提示文案
- 编辑器 chromeH 估算需随工具栏行数复核
