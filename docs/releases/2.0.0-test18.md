# 2.0.0-test18 更新说明

本次将随手夹改为刘海照片墙入口，并补齐文件中转、钉图缩放与拖拽状态处理。已安装本地测试版；本记录对应源码更新，不代表已发布通用安装包。

## 照片墙

- 入口固定在刘海下沿，按系统报告的安全区域避让摄像头；无刘海屏幕顶部居中。旧的入口拖动位置不再使用。
- 点击入口或使用已配置的剪贴板快捷键展开；普通悬停不展开。主动打开后保持可见，点击外部、入口或 Esc 收起。
- 文件拖入停留约 320ms 展开，直接松手也可接收；放入成功约 900ms 后收起。
- 拖入后离开保留约 650ms 缓冲，再恢复原状态。拖出期间保持展开，目标接受后约 300ms 收起，取消或拒收保持展开。
- 图文按内容比例显示拍立得卡片，保留高亮过渡、夹子移除与撤销、图片钉图、分页和历史入口。

## 文件中转和钉图

- 可从 Finder 复制多个文件或拖入入口，支持 PDF、MD、Word、Excel 等普通本地文件。
- ⌘ 点击文件卡片多选，再拖往支持附件的应用。仅记录源位置；移除记录不会删除原文件。目录与应用包不在基础版范围内。
- 原文件移动或删除后提示重新挂入；目标应用决定是否接受拖出的内容。
- 钉图支持拖动四边、四角等比缩放，提供缩放光标和角部手柄；图内拖动仍用于移动，OCR 模式保留选区操作。
- 展开、接收和移除支持系统触觉反馈，可在通用设置中关闭。

## 兼容与验证

- 保持原有数据、自定义快捷键、固定签名和菜单栏常驻方式；不显示 Dock 图标。
- 116 项自动化测试通过，覆盖拖入停留、离开缓冲、取消恢复、接受后收起及多屏坐标计算等。
- 本地 Test18 启动检查：辅助功能已授权，现有 ⇧⌘Z 快捷键注册成功，入口位于笔记本刘海下方。
- 当前实机仅连接一块笔记本屏幕；外接屏实际表现仍需连接后验证。新硬件的摄像头区域兼容依据系统报告，不代表所有机型均已实测。
