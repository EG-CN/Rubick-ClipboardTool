# 2.0.0-v3 晾衣架重做

> 2026-11-01 ~ 11-02 · 分支 `codex/clothesline-v3`（已快进合并 main）· 未打 tag、未发 Release
> 本记录对应已安装本机的版本；安装包未重新发布，test18 的 Release 仍是最新可下载版本。

## 概览

test18 的随手夹是「常驻刘海入口 + 底部工具条」的固定照片墙。v3 按定稿方向整体重做为**瞬态晾衣架**：平时屏幕上没有任何入口，有新内容时绳子自动垂下，用完自动收起；拖文件到刘海即可挂入。

## 交互机制

| 场景 | 行为 |
| --- | --- |
| 复制 / 截图 / 挂入文件 | 绳子在鼠标所在屏幕自动垂下；重复内容去重置顶同样触发；主面板打开时不抢戏 |
| 拖文件到刘海 | 刘海下浮现虚线引导框「把文件拖到这里挂上绳」，松手挂绳；绳子保持垂下可继续拖出 |
| 取用 | 单击粘贴（送达约 0.3s 后自动收绳）；拖出使用；⌥点击仅复制；文件 ⌘ 多选 |
| 浏览 | 空白绳面按住拨动或滚轮滑动；滑动浮出「3–7 / 7」瞬时计数，停手淡出 |
| 悬停 | 卡片聚焦提亮、其余压暗；光标扫过绳面卡片让位摆动（proximity 物理 + 悬挂微晃） |
| 收绳 | 取用送达 / 取空 / Esc / 点击外部 / 右键「收起晾衣架」 |
| 更多 | 右键菜单：打开主面板 / 收起晾衣架 / 操作提示 / 打开设置 |

与 test18 的关键差异：

- 删除常驻刘海入口与底部工具条（分页、历史、···、收起按钮全部取消，能力并入手势与右键菜单）。
- 挂入文件后不再 0.9s 自动收起，保持垂下便于继续拖出。
- 触觉铺点：垂绳（轻点）/ 摆动掠过卡片（轻点）/ 移除夹子（实锤）/ 挂入文件（滑档）/ 收绳（滑档）。

## 视觉

- 绳两端黄铜挂钉，绳体麻绳质感。
- 卡片改用金属弹簧夹，铬 / 黄铜双变体按卡片身份确定性分配。
- 拍立得相纸：暖白纸面、细边框、柔和长投影，底部图注（标题 / 尺寸或时间 / 状态点）。

## 接取区设计迭代（三次定稿）

1. 屏幕最顶缘窄条 + 拖拽会话检测布防 → 与系统调度/分屏手势冲突，废弃。
2. 刘海下方固定区 + hitTest 恒穿透 → 用户瞄准的是刘海本体，光标进刘海带不命中；且恒穿透会连拖拽投递一并拦掉，废弃。
3. 定稿：接取区常驻刘海带（自屏幕顶缘覆盖刘海本体下探 34pt，宽 260pt 居中），平时点击穿透；全局鼠标监听检测到文件拖拽会话（拖拽剪贴板出现 fileURL）时变为实体并可接收，同时显示虚线引导框；绳子已垂下时引导框隐藏，由绳面直接接收。
