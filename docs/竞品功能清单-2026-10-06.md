# 竞品功能调研与 RubickBoard 功能清单（2026-10-06）

> 调研对象：Snipaste、PixPin、CleanShot X、iShot、Xnip、Shottr、Flameshot、ShareX。
> 拉比克定位基准：**本机优先、零云依赖、快捷键驱动**的剪贴板+截图+贴图+OCR 一体化工具。与定位冲突的功能（云上传/账号/社交）明确不列。
> 状态标记：✅ 已有 · 🔶 部分实现 · ⬜ 缺失。优先级：T1 直接补齐竞争力 / T2 差异化 / T3 观察。

## 一、竞品招牌功能速览

| 竞品 | 招牌 |
|------|------|
| Snipaste | 贴图最佳（缩放/旋转/透明度/鼠标穿透/批量/分组）、极简轻快 |
| PixPin | 免费全家桶：长截图 + 贴图OCR + GIF 录制 + 表格识别，Snipaste 贴图的超集 |
| CleanShot X | macOS 售价标杆：50+ 功能（滚动截图、OCR、贴图、云上传、录屏、隐藏桌面图标、背景美化、快速访问浮层） |
| iShot | 国产全家桶：长截图/贴图/取色/录屏/延时截图/多窗口截图/截图加壳 |
| Xnip | 标注时调整选区大小、窗口阴影、OCR、贴图（免费版水印） |
| Shottr | 极快极轻、文字打码、屏幕标尺测量、贴图 |
| Flameshot | 开源、即时标注 |
| ShareX | 工作流自动化、动作链 |

## 二、拉比克现状对照

✅ 已有：区域/窗口截图、智能选窗、两段式选区+8手柄、标注九件套（矩形/椭圆/箭头/画笔/文字/序号/马赛克/模糊/高亮）、贴图（拖/缩/透明度/⌘C/划字OCR）、长截图（实验）、划词翻译、划图取字、剪贴板历史（文本/图片/文件+标签+搜索+多选）、Dock、放大镜取色 UI。
