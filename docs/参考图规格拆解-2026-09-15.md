## C. 剪贴板 — 底部 Dock 面板（图3）

### C1 面板形态
- 贴屏幕底部的圆角大面板（顶部两角大圆角），毛玻璃材质、透出壁纸色调。
- 与现有 ShellDock 同形态，但在其上大幅增强。

### C2 顶栏（单行）
- 最左：App logo。
- 搜索框：占位「搜索」，标注 **⌘F** 快捷键聚焦。
- 类型/标签筛选：`全部`（选中态为深色胶囊）+ 带彩色圆点的条目 + `+`（新建标签）+ 最右 `…` 更多菜单。
  - 前 5 个是**内容类型**：文本 / 图片 / 链接 / 颜色 / 文件。
  - 后面是**用户自定义标签**（参考图中示例：人工 / 工作 / 收藏 / 测试）。
- 结论：类型筛选与标签筛选混排在同一行，圆点颜色区分。

### C3 卡片结构（横向单行滚动）
每张卡片：
- 左上角**序号数字**（1、2、3…，疑对应数字键快粘贴，待确认）。
- 顶部中央**彩色类型徽章**：文件=红、图片=绿、链接=蓝、颜色=深灰、文本=紫。
- 中部**内容预览**（按 kind）：
  - 文件：大文件图标 + 文件名 + 路径 chip（如 `~/Downloads`）。
  - 图片：缩略图。
  - 链接：站点截图/图标 + 页面标题 + URL。
  - 颜色：大色块 + HEX 值（如 `#609400`）。
  - 文本：多行摘要截断。
- 底部**元信息行**：来源 App 图标 + 相对时间（刚刚 / 24 分钟）+ 尺寸信息（图片=分辨率·大小；链接/文本=字符数；文件=大小）。
- 卡片 2 带蓝色描边 = 选中/悬停态。
