**macOS 菜单栏剪贴板魔法工具** —— 致敬大魔导师 Rubick：他偷取对手的技能，你偷取一切内容。
对应功能清单：`../剪贴板截图工具-功能清单-v1.md`；交互原型：`../剪贴板工具原型/`。

### 剪贴板样式：原生 / Dock / 随手夹

在「设置 → 剪贴板 → 面板形态」切换，立即生效并在重启后保留。现有用户的默认样式不变。

- **原生**：完整双栏历史面板。
- **Dock**：底部卡片，沿用现有操作。
- **随手夹**：截图、复制图片和文字共用已有历史，自动挂到屏幕顶部；每块显示器独立定位。入口固定在刘海下沿，普通外接屏使用顶部居中入口；绳长适应屏幕可用宽度，图文按内容生成不同尺寸的拍立得卡片。点击入口展开照片墙，普通悬停不展开；点外部、再次点击入口或 Esc 收起，已配置的剪贴板快捷键或菜单入口重新展开，支持完全隐藏。
- 单击卡片向仍然聚焦的输入框发送粘贴；⌥ 单击仅复制。关闭自动粘贴或无法确认输入框时仅复制并提示；不会自动发送消息。需要辅助功能权限，目标应用也需支持对应格式。
- 拖动图片提供文件 URL、PNG/TIFF，拖动文字提供完整纯文本。能否接收由目标应用决定，取用不会重复入册。
- 点击夹子删除对应图文历史记录，5 秒内可在随手夹底部撤销；图片右下角「钉图 / 收回」管理贴图；中央工具条提供前后翻页、页码、历史与收起；更多菜单可打开设置或隐藏入口。滚轮也可分页。隐私过滤和历史数量上限沿用现有设置。
- 拉比克自身截图期间临时隐藏随手夹，结束或取消后恢复。原生预览：`--clothesline-preview <输出目录>`（使用独立示例数据）。

## 技能（功能）

- 📌 **铭刻 · 桌面钉图**：置顶贴图，拖动/滚轮缩放/双击取消
- ⌨️ **全键可配置**：所有快捷键可自定义 + 冲突检测
- ⚙️ 菜单栏常驻、开机自启、深浅色、单实例；数据仅存本机

## 常见问题：辅助功能授权「勾了也没用」

**原因**：ad-hoc 签名每次构建指纹都会变，系统把新版本当成另一个 App，之前的授权自动失效。

**一次性解决**：

```bash
./scripts/setup-signing.sh             # 首次配置固定证书
./scripts/rebuild-and-install.command   # 构建、校验身份并重装
```

然后到 系统设置 → 隐私与安全性 → 辅助功能：先选中旧的「拉比克」条目按 **−** 删除，再按 **+** 添加新包（或等它弹窗），重启应用即可。

钉图支持拖动四边或四角等比缩放，拖图内部移动；双击关闭、原有滚轮和捏合缩放仍可用。OCR 划选时不启用边缘缩放。

### 随手夹 · 文件中转（基础版）

- Finder 一次复制多个文件，或把多个文件拖到小夹子上，分别挂成文件卡片；支持 PDF、MD、Word、Excel 等本地文件，以系统类型图标展示。
- 拖动文件卡片到支持附件的聊天框、邮件或文档；⌘ 点击多选文件，可一次拖出多个，工具条显示选中数量。
- 文件只登记源位置，不移动原文件；移除记录、清空历史都不删除源文件。源文件被移动或删除后会提示重新挂入，避免拖错内容。
- 目录和应用包不纳入本次基础版。拖出按复制交付，能否接收附件由目标应用决定。
- 固定入口和卡片夹子具有悬停操作提示；更多菜单可查看操作说明。

随手夹快捷键提示读取实际配置，不覆盖自定义键位；显式呼出后保持展开，直到取用成功、点外部或主动收起。隐藏后可用同一快捷键恢复。
展开、文件放入、夹子移除支持系统触觉反馈，可在「通用」关闭；普通卡片悬停不触发。卡片夹子悬停显示「移除」提示，展开及高亮使用短暂淡入过渡。
钉图边角由独立 AppKit 操作层处理，支持四边、四角等比拖拽，带缩放光标与角部手柄；内部仍用于移动图片，OCR 模式不抢选区事件。

### 刘海照片墙交互

入口根据系统报告的屏幕安全区域和摄像头避让区域定位，不在摄像头内放控件；无刘海外接屏顶部居中。旧的入口拖动位置不再生效。

- 主动打开后保持展开，不因鼠标离开而消失；支持点击入口、点外部和 Esc 收起。
- 拖文件在入口停留约 320ms 展开；直接松手也能接收。接收确认约 900ms 后收回。
- 文件拖入后又离开，保留约 650ms 的连续区域缓冲，再恢复拖入前状态。
- 拖出时冻结展开；目标确认接受后约 300ms 收起，取消或拒收则保持展开供重试。复制取用不删除记录。
- 文件、图片、文字、移除及撤销、钉图继续可用；截图期间暂时隐藏照片墙。
