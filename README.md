## 技能（功能）

- 📋 **魔典 · 剪贴板历史**：文字/图片自动入册，去重、上限可调、重启保留、忽略密码管理器；⌘⇧V 呼出，单击预览、双击或回车确认，面板可拖动和调整大小
- ✨ **奥术之眼 · 截图**：⌘⇧A 框选，所见即所截（绿框跟手、原尺寸输出）；框选后**原地标注**，单行工具栏支持复制、保存与钉图
- 🖊️ **附魔 · 标注**：矩形（三档圆角）、椭圆、箭头（三线 V 形头）、画笔、文字（点哪写哪、可再编辑可拖动）、马赛克/模糊——Shift 锁定正方形/正圆/45°/直线，撤销重做，全部快捷键可自定义
- 🔍 **识读 · 划图 OCR**：截图后一键「识图」或钉图/历史图片划选，Vision 本地识别（离线免费）；选中文字按 T 直译、⌘C 复制
- 🌐 **万国语言术 · 翻译**：历史文本一键翻译；⌘⇧D **划图翻译**（滑选屏幕任意文字 → 自动识别+翻译，Bob 式）；默认 Apple 离线引擎，可配 OpenAI 兼容大模型
- 📌 **铭刻 · 桌面钉图**：置顶贴图，拖动/滚轮缩放/双击取消
- ⌨️ **全键可配置**：所有快捷键可自定义 + 冲突检测
- ⚙️ 菜单栏常驻、开机自启、深浅色、单实例；数据仅存本机

## 安装

已有发布版本可从 Releases 下载 zip → 解压 → 拖入「应用程序」→ 首次打开**右键 → 打开** → 授权**辅助功能**（自动粘贴）与**屏幕录制**（原地截图；系统框选需主动选择）。详见包内安装说明。

## 技术

Swift + SwiftUI 原生（macOS 14+）；Vision（OCR）为系统离线能力；Apple 离线翻译需 macOS 26+（更老系统可配置大模型翻译）。

## 开发者

- 本地构建：`./scripts/make-app.sh --universal`（需 Xcode）
- 一键重装（本地测试）：`./scripts/rebuild-and-install.command` —— 先运行 `scripts/setup-signing.sh` 配置固定签名，更新前会校验身份一致

## 常见问题：辅助功能授权「勾了也没用」

**原因**：ad-hoc 签名每次构建指纹都会变，系统把新版本当成另一个 App，之前的授权自动失效。

**一次性解决**：

```bash
./scripts/setup-signing.sh             # 首次配置固定证书
./scripts/rebuild-and-install.command   # 构建、校验身份并重装
```

然后到 系统设置 → 隐私与安全性 → 辅助功能：先选中旧的「拉比克」条目按 **−** 删除，再按 **+** 添加新包（或等它弹窗），重启应用即可。
